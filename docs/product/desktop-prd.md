## 1. 产品概述

**一句话**:本地优先、自用的求职训练工作台——每天打开先训练(SM-2 间隔重复),AI 出题经人工把关进库,JD 与简历提供定向输入;数据全部留在本机。

**用户**:前端工程师 / 想转 AI Agent 方向的工程师,求职备考期每天使用,键盘熟练,重视数据私有。

**核心循环**:
```
每日循环: 打开 → 今天(计划) → 学习一轮(先想后看 → 评分 → 自动推进) → 小结(下次复习时间)
弹药循环: 添加题目(手动 / AI / 按 JD)
            ├─ 手动写题 ──────────────→ 我的题库(人写即人审,直接入库)
            └─ AI / 按 JD 生成 → 待审核(通过 / 拒绝) → 通过 → 我的题库
我的题库 → 待学习 → 进入每日循环
```

**设计原则**(九条,详见 from-zero-redesign §2):
打开即训练 / 桌面工作台范式(源列表+内容+状态栏,13–15px 密度)/ 学习=窄栏阅读仪式(≤38rem)/ 管理面=列表+详情双栏就地操作 / 质量闸=待审核工作台 / 术语一词一义 / 本地优先要被看见 / 不可逆=确认弹窗、编辑离开=守卫 / 官方只读复制副本。


- 侧栏序 = 频率 × 工作流;待审核带计数徽标;今天徽标 = 待复习+待学习+待审核之和。
- ⌘K 全局命令面板(见 M9)。
- 深链:JD 详情→添加题目(预选高亮)/ ⌘K 题目→题库选中 / 题库详情→单题直练 / 今日计划→待审核。
- `document.title = {页面} · CommitCareer`;侧栏无品牌名。

### 2.2 全局键盘

| 键 | 语境 | 行为 |
|---|---|---|
| ⌘K | 全局(含输入框) | 命令面板 |
| ⌘1…8 | 输入框外 | 切表面(顺序=侧栏序) |
| ␣ / Enter | 学习·未揭示 | 揭示答案 |
| 1 / 2 / 3 | 学习·已揭示 | 不会 / 模糊 / 掌握 |
| F | 学习 | 专注模式开关 |
| Esc | 弹窗 > 面板 > 专注 | 逐层退出 |
| ↑ / ↓ | 题库 / 待审核列表 | 移动选中行 |

### 2.3 全局模式

- **不可逆确认弹窗**:删除题 / 删除 JD / 拒绝。标题问句 + 正文写明不可恢复与连带清理范围 + 危险色确认按钮 + 取消。
- **未保存守卫**:JD 表单 / 简历编辑器 dirty 时离开 → 「有未保存的修改」→ 继续编辑 / 放弃修改并离开(放弃 = 恢复已保存内容)。
- **空态原则**:每个列表/面板都有空态文案 + 下一步动作按钮;零值不出现(今日计划)。

## 3. 模块详设

### M1 今天(路由 `/`)

**目标**:打开即今日训练;30 秒内开始学习或完成把关。

**布局**:
```
┌ 今天 ────────────────────────────── [添加题目] ┐
│ 学习计划(左上,主卡)        │ 未来 7 天到期   │
│  N 待复习   [开始复习 N 题]  │  ▂▄▁▂▅▂ 迷你柱 │
│  N 待学习   [开始学习 N 题]  ├ 累计 ──────────┤
│  N 待审核   [去审核]         │ 42 已学 18 已掌握│
│ 最近学习记录(左下)          │ 12 天 连续学习  │
└──────────────────────────────────────────────┘
```

**交互**:
1. 三行计划,数字色分:待复习琥珀 / 待学习朱砂 / 待审核灰;行内主按钮立即开对应会话或跳审核。
2. **零值行不出现**;三者全空 → 「今日队列已清空 / 复习与新题都完成了,明天见」+「再过一遍」。
3. 评分、审核通过/拒绝后,计数与徽标**实时联动**(非静态)。
4. 未来 7 天柱状:峰值朱砂标注;hover 显示当日到期数。
5. 最近学习记录:日期 · 学习了 N 道题,掌握 N 道 · 时间。

**验收**:零值行隐藏;全清态出现;评分后今天计数立即下降;按钮直达对应会话。

### M2 学习(路由 `/session`)

**目标**:一轮高质量回忆训练——强制思考、低打断、评分驱动排期。

**布局**(题卡 ≤640px 居中):
```
学习 · 待复习 · JS 原理        [专注 F] [退出学习]
1 / 5 ━━━━━━━━━━━━━━━━━━━━━━━━━━━ 20%
┌─ [中][代码题][来自 JD][重练][高频] ─┐
│  题干(宋体 22px,专注 27px)          │
│  考察方向(灰)                        │
│  ── 揭示后 ─────────────────────    │
│  参考答案要点(关键句加粗)           │
│  追问 · 面试官可能接着问             │
│  [代码草稿纸: 编辑器 | 运行 | 输出]  │
├─────────────────────────────────────┤
│   [我想好了,看答案 ␣]  或            │
│   [不会 1] [模糊 2] [掌握 3]  [问 AI] │
│   副说明:先想后看 / 评分决定复习时间  │
└─────────────────────────────────────┘
```

**交互流程**:
1. **入会话**:来源=今日计划(待复习 / 待学习)/ ⌘K / 学习空态页 / 单题直练;池=对应状态题,「待复习优先、待学习补位」。
2. **揭示前**:唯一主按钮「我想好了,看答案」+ 空格/Enter;此阶段可展开代码草稿纸写思路、可问 AI。
3. **评分**:1/2/3 或点击 → toast 反馈(「已掌握 · 7 天后再学」/「模糊 · 3 天后再学」/「不会 → 稍后再出现一次」)→ 题面 220ms 淡出 → 自动下一题。
4. **「不会」重排**:本题复制排到本轮末尾重练一次(重练徽标),原题按评分排期。
5. **小结**:统计行 + 逐题行(规范术语评分 + 下次复习时间)+ 回到今天 / 再过一遍(全部题)。
6. **专注模式**(F):侧栏/状态栏隐藏、页头文字隐去、题面放大、右下浮出「退出专注 Esc」;Tauri 壳内联动系统全屏;Esc 退出。
7. **代码草稿纸**:按题保存;CodeMirror(closeBrackets 关闭);运行=Web Worker 沙箱,超时 3s 强杀,异步 console 输出继续转发;切题防抖保存。
8. **问 AI**:独立子窗口(已开聚焦);登录一次常驻;远端页零 IPC;浏览器层降级新标签页。
9. **空态**(侧栏直入且无进行中会话):「从这里开始一轮学习」+ 三快捷入口;进行中会话保留,切走再回不丢。

**边界**:Esc 不加输入框守卫(焦点常驻编辑器,守卫会让 Esc 够不到);空格仅在未揭示时劫持。

**验收**:空格揭示→1/2/3 评分→自动推进全键盘走通;「不会」题本轮出现两次;小结评分列只用规范术语;专注模式壳全隐且 Esc 恢复;草稿纸运行 `console.log` 可见输出、切题回来内容还在。

### M3 题库(路由 `/library`)

**目标**:题库是个人资产表——快速找到题、看清状态、就地操作。

**布局**(双栏,右侧 360px):
```
题库 ──────────────────────────────── [添加题目]
(前端工程师)(AI Agent 工程师)(我的题库 N)
[🔍 搜索题干/考察点…]
|状态| 全部 待学习 待复习 已掌握 ‖难度‖ 不限 初中高 ‖来源‖ 不限 官方 手动 AI JD   [全部模块▾] N 题
┌───────────────────────────┬──────────────────────┐
│ 题号|题干|模块|难度|状态|下次复习|🔖 │ 详情: meta 药丸      │
│ (表头点击排序,↑↓ 选行)     │  题干                │
│                           │  考察方向·下次复习    │
│                           │  [学习此题][编辑][删除]│
│                           │  参考答案要点          │
│                           │  追问                 │
│                           │  笔记(就地编辑)       │
└───────────────────────────┴──────────────────────┘
```

**交互**:
1. 分类切换:官方两类只读 + 我的题库;来源徽标在题干行内(来自 AI/JD/手动)。
2. 筛选:状态/难度/来源为**带组标签的芯片组**,模块为下拉(随分类);搜索匹配题干/考察点/题号;组合生效,计数实时。
3. 排序:表头点击切换升/降;↑/↓ 移动选中行(自动滚动可见)。
4. 详情操作按归属分化:**官方题**=学习此题 + 复制到我的题库;**我的题**=学习此题 + 编辑(就地表单:题干/答案要点)+ 删除(确认弹窗,连带清进度/笔记/草稿)。
5. 笔记:无→「+ 写笔记」;有→展示 + 编辑;表格行尾书签图标标识。
6. 空态:无匹配→「没有匹配的题」+ 清除筛选;我的题库空→引导添加题目。

**验收**:官方行无编辑/删除、有复制;我的行反之;筛选排序搜索组合正确;笔记保存后行内出现书签标;删除有确认且计数联动。

### M4 待审核(路由 `/library?tab=review`)

**目标**:AI 产物的质量闸(ADR-10)——把关即学习,库永远干净。

**布局**(双栏同题库):
```
待审核 · N 题待审核;AI 生成的题通过后才进学习队列    [返回今天]
┌───────────────────────────┬──────────────────────┐
│ 来源行(AI 生成·知识点X /   │ [待审核][难度]        │
│       按 JD 生成·岗位名)   │  题干                │
│ 题干                      │  考察方向            │
│ ↑↓ 选行                   │  [通过,进我的题库][拒绝]│
│                           │  参考答案要点          │
└───────────────────────────┴──────────────────────┘
```

**交互**:选中即预览;**通过**=立即入我的题库+学习队列(计数联动);**拒绝**=确认弹窗(永久删除)后移除;↑/↓ 选行;处理完自动选中下一题;空态=「没有待审核的题」+ 去添加题目。

**验收**:通过后我的题库+1、待审核-1、徽标联动;拒绝必经确认;队列清空出空态。

### M5 添加题目(路由 `/add`)

**目标**:统一出题入口;三种来源一条管线,产物去向清晰(手动直接入库,AI/JD 先待审核)。

**布局**(三段平铺,不用页签):
```
添加题目 · 手动写的直接进我的题库;AI 与按 JD 生成的先进待审核
┌ 手动写题(左卡) ──────────┐ ┌ AI 生成(右上) ─────────┐
│ 题干* / 考察方向* / 难度   │ │ 知识点*                 │
│ 答案要点*(每行一条,≥50字) │ │ [生成题目]               │
│ [保存到我的题库]           │ │ 生成中…/已生成 N 题→[去审核]│
└──────────────────────────┘ ├ 按 JD 生成(右下,可高亮) ─┤
                            │ ( ) JD 单选卡 × N         │
                            │ ☑ 结合简历,生成深挖题     │
                            │ [按 JD 生成题目]           │
                            └──────────────────────────┘
```

**交互**:
1. 手动:必填校验(题干/考察方向/答案要点)→ 保存直接 approved 入我的题库(人写即人审),表单清空,toast。
2. AI:知识点必填;提交→ spinner「正在按知识点出题,数量由 AI 判断…」(prompt 内嵌质量红线,预检自修正)→ 结果内联 + 「去审核」直达。
3. 按 JD:单选 JD 卡 + ☑ 结合简历出深挖题;提交 → 生成中 → 待审核。
4. **深链**:`?jd=<id>` 预选该 JD 并高亮按 JD 段(从 JD 详情「按 JD 生成题目」进入)。

**验收**:手动保存后我的题库+1 且来源=手动;AI/JD 生成后待审核+1;深链预选高亮正确;必填缺失有提示。

### M6 JD 管理(路由 `/profile?tab=jd`)

**目标**:多 JD 资产 + 各自的出题管线视图。

**布局**(双栏,左 300px):
```
JD 管理 · 可按 JD 生成题目,结合简历出深挖题    [新增 JD]
┌ JD 列表(最近使用置顶) ─┬ 详情 ────────────────────┐
│ 岗位名                │ [公司][最近使用]           │
│ 公司 · N 日使用  (选中)│ 岗位名                    │
│                       │ N 待审核|N 已入我的题库|N 已掌握│
│                       │ [按 JD 生成题目][编辑 JD][删除]│
│                       │ JD 正文                    │
│                       │ ── 我的简历 ── N 字 [编辑简历]│
└───────────────────────┴───────────────────────────┘
(新增/编辑态: 详情栏变就地表单 岗位名*|公司|JD 正文* [取消][保存 JD])
```

**交互**:
1. 选中 JD → 详情;最近使用自动置顶(使用=生成过题目或刚编辑)。
2. 新增/编辑 = 详情栏就地表单,**dirty 守卫**(切 JD / 离开页面都拦);保存后「最近使用=刚刚」。
3. 删除 = 确认弹窗(已生成题不受影响)。
4. 「按 JD 生成题目」→ 深链 `/add?jd=<id>`;「编辑简历」→ 简历管理。
5. 管线统计三数随审核/学习实时联动。

**验收**:新增保存后置顶出现;编辑中途离开触发守卫、放弃恢复原文;删除确认后列表更新;深链目标段高亮且预选。

## 4. 数据与依赖(概要)

- **SQLite(本机)**:review_state(进度)/ notes / code_drafts / questions(我的+物化官方)/ jds / profile(简历)/ secrets(key)。零上传。
- **LLM**:OpenAI 兼容抽象(智谱/DeepSeek/Ollama);生成 prompt 内嵌 QUALITY 红线 + 预检自修正。
- **官方库**:包内 questions.json 播种 → 启动自动 + 手动同步远端;下架题连带清进度/笔记/草稿,id 作废不复用。
- **Web 层回归**:e2e mock Tauri IPC 与 LLM;真机(真 SQLite/权限/LLM)以 `npm run tauri dev` / smoke 验证——验收报告须注明覆盖层。

## 5. 非功能需求

1. **键盘可达**:全部核心动作有快捷键(§2.2);Tab 顺序符合视觉顺序;focus-visible 可见。
2. **本地优先可见**:状态栏常驻标识;简历/key 处「只存本机」。
3. **术语合规**:全部 UI 文案过术语表;禁词(草稿区 / 生题 / 定向生题 / 新题 / 没学过 / 未学 / 档案 / 刷题 / 待确认 / 待审)零出现。
4. **性能**:题库表格滚动流畅(虚拟化按需);评分推进 <300ms 感知。
5. **可访问性**:色彩不做唯一信息通道;尊重 prefers-reduced-motion。
6. **动效**:150–220ms;不因 hover 引起布局位移。
