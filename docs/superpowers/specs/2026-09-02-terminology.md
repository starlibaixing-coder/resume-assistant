# UI 术语表

- **日期**:2026-09-02
- **性质**:用户指示「先把术语表定一下,各个地方都不统一」。全量盘点 desktop 用户可见文案后统一;三个分叉点(待审核/待学习/学习队列)经用户逐项确认。
- **效力**:UI 文案(页面标题、按钮、标签、toast、空态与说明句)只用本表术语;代码标识符与 ADR/计划文档保留工程术语(drafts / pending / 草稿区 / unseen / remaining / my 等)。

## 固定短语

- 出题统一入口:**「添加题目」页**(`/add`,2026-09-03 用户确认弃弹窗改页面;页内三段平铺——手动写题 / AI 生成 / 按 JD 生成,不用页签)。手动保存直接进我的题库(落题目列表);AI 与按 JD 先进待审核。各页面不再有独立「AI 生成题目」按钮;JD 条目行内「按 JD 生成」为深链 `/add?jd=<id>` 的捷径。
- 工作台快捷入口(总览右侧单卡):「开始复习」「开始学习」「去审核」「添加题目」——零计数的条目不出现;求职两行(JD/简历)并入此卡,不再单开「求职」面板。总览左栏为平铺小节(学习中/未开始/最近动态),分类卡不套面板框。
- 列表页三入口(2026-09-10 起):**「复习 · 到期 N 题」「学习 · N 题」「练习全部题目」**(弃「开始」前缀)
- 句内量词用「道题」(已累计学习 1 道题 / 学习了 X 12 道题),数字标签后保持裸数字(待学习 147)——2026-09-03 用户修正
- 总览分类卡按状态分组:「学习中」(learned > 0)与「未开始」(learned = 0)两个面板,未学过的分类不冒充学习进度(2026-09-03 用户确认)
- 数字标签格式:「待复习 N」「待学习 N」「待审核 N」「已掌握 N」——术语后跟数字,不加量词
- 「是哪些题」深链:待复习 → `browse?status=due`;待学习 → `browse?status=unseen`

## 动词与板块名(2026-09-03 用户确认)

- UI 动词统一「学习」,不用「刷」:累计学习 / 学习了 N 道 / 学习页 / 学习队列;分类页顶部说明「之前学过…」。
- 总览(工作台式)板块名:「学习中」(分类卡面板,未开始的分类也在列,卡片「待学习 N」自说明)、「最近动态」「快捷入口」「求职」。
- 空态文案一个动词:求职行空态「添加 / 填写」,整行可点;不写「还没有…去…」类重复句。

## 禁止上 UI 的词

草稿区、生题、定向生题(→ 按 JD 生成题目)、档案(→ 已保存)、新题、没学过、未学、刷题队列、复习队列、待确认、待审(→ N 题待审核)、刷题(→ 学习)。

## 产物方式

盘点脚本级 grep(`desktop/src` 全部 .tsx 用户字符串);历史演进:2026-08-31 命名表(brand-naming.md)→ 2026-09-02 IA 重构修订 → 本表,冲突以本表为准。
