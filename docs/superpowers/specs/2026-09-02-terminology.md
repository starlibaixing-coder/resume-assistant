# UI 术语表

- **日期**:2026-09-02
- **性质**:用户指示「先把术语表定一下,各个地方都不统一」。全量盘点 desktop 用户可见文案后统一;三个分叉点(待审核/待学习/学习队列)经用户逐项确认。
- **效力**:UI 文案(页面标题、按钮、标签、toast、空态与说明句)只用本表术语;代码标识符与 ADR/计划文档保留工程术语(drafts / pending / 草稿区 / unseen / remaining / my 等)。

## 固定短语

- 分类页双按钮:**「开始复习 N 题」/「开始学习 N 题」**(成对;用户自选刷法)、「再过一遍(全部题)」
- 数字标签格式:「待复习 N」「待学习 N」「待审核 N」「已掌握 N」——术语后跟数字,不加量词
- 「是哪些题」深链:待复习 → `browse?status=due`;待学习 → `browse?status=unseen`

## 禁止上 UI 的词

草稿区、生题、定向生题(→ 按 JD 生成题目)、档案(→ 按实际对象称呼,如「已保存」)、新题、没学过、未学、刷题队列、复习队列、待确认、待审(→ 副标题用「N 题待审核」)。
