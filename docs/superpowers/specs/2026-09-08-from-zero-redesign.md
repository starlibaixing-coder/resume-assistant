## §2 结构结论(设计原则)

从上述文档推出的九条,每条都能回指文档依据:

1. **打开即训练**。产品主体是每天的训练,不是管理后台——首屏是今日学习计划,没有仪表盘/营销 hero。(README:SM-2 刷题是核心;「自用为主」ADR-2)
2. **桌面工作台范式**。源列表侧栏 + 内容区 + 状态栏;13–15px 正文、信息一屏可见;键盘是一等公民。(v2 用户修正确认:全屏卡片流+大字 hero 是移动端范式)
3. **学习 = 窄栏阅读仪式**。题干区 ≤ 38rem 行长(65–75ch 阅读规范);「先想后看」强制回忆;评分后自动推进,不打断心流。(README:强制思考)
4. **管理面 = 「列表 + 详情」双栏,就地操作**。题库/待审核/JD 管理共用此范式;编辑在详情栏内完成,不放弹窗、不放展开抽屉。
5. **质量闸 = 待审核工作台**(ADR-10):通过 → 我的题库+学习队列;拒绝 → 确认后永久删除。审题入口在侧栏一级 + 今日计划第三项。
6. **术语一词一义**(术语表全文生效),动词只用「学习」,评分按钮固定 不会/模糊/掌握 + 1/2/3 快捷键。
7. **本地优先要被看见**:状态栏常驻「本地优先 · 数据不上传」;简历栏「只存本机」徽标;设置页 key「仅存本机」。
8. **不可逆 = 确认弹窗;编辑离开 = 未保存守卫**。删除题/删除 JD/拒绝走 AlertDialog 风格弹窗;JD 表单与简历编辑器有 dirty 守卫,「放弃修改」恢复已保存内容。
9. **官方题只读,复制副本后可改**(ADR-3)。官方行操作=复制到我的题库;我的行操作=编辑/删除。

## §4 各表面规格

### 4.1 今天

- **学习计划**(左栏第一卡):三行——待复习(N,琥珀数字)/ 待学习(N,朱砂数字)/ 待审核(N,灰数字);行内主按钮 **开始复习 N 题** / **开始学习 N 题** / 去审核。**零值行不出现**;三者皆空 → 单行「今日队列已清空」+「再过一遍」。
- 右栏:**未来 7 天到期**迷你柱状(峰值朱砂标注)+ **累计**(已学题目/已掌握/连续学习 N 天)。
- 左栏第二卡:**最近学习记录**(日期 · 学习了 N 道题,掌握 N 道 · 时间)。
- 右上:添加题目。
- 评分、审核通过/拒绝后计数即时联动(不是静态展示)。

### 4.2 学习(会话)

结构自上而下:

1. **会话头**:范围说明(待复习 / 待学习 / 全部题 · 待复习优先 / 单题 · 题号)+ 模块;右侧 专注(F)/ 退出学习。
2. **进度条**:N / M + 细进度线。
3. **题卡**(≤640px 居中):
   - meta 药丸:难度 / 代码题 / 来自 JD·AI / **重练** / 标签
   - **题干**:宋体 display,22px(专注模式 27px)
   - 考察方向(灰字)
   - 未揭示:唯一主按钮「我想好了,看答案 ␣」+ 副说明「先在脑中想清楚…」+ ghost「问 AI」
   - 揭示后:**答案要点**(加粗关键句)+ **追问**块(「面试官可能接着问」)+ 评分三按钮 **不会 1 / 模糊 2 / 掌握 3** + 副说明
   - 代码题:揭示后展开**代码草稿纸**(textarea + 运行按钮 + 输出区;真实 JS 执行,输出 console;按题暂存)
4. **评分交互**:点击/快捷键 → toast 反馈(「已掌握 · 7 天后再学」/「模糊 · 3 天后再学」/「不会 → 稍后再出现一次」)→ 题面 220ms 淡出 → 自动下一题。**「不会」的题复制一份排到本轮末尾重练一次**(重练徽标),原型实现为副本入队、原题状态记「明天」。
5. **小结**:本轮学习完成(学习了 N 道题,掌握 N 道,偏弱 N 道已排进明天)+ 逐题行(规范术语评分 + 下次复习时间)+ 回到今天 / 再过一遍。
6. **空态**(侧栏直接进学习且无进行中会话):「从这里开始一轮学习」+ 三个快捷入口。
7. **专注模式**(F 切换,Esc 退出):侧栏/状态栏隐藏、页头文字隐去、题面放大;右下浮出「退出专注 Esc」。纸面不换墨底(夜读由外观设置承担,见 §8)。

### 4.3 题库

- **分类切换**(顶部药丸分段):前端工程师 / AI Agent 工程师 / 我的题库(N)。
- **查询栏**:搜索(题干/考察点/题号)+ 三个筛选组(**组标签**:状态 全部·待学习·待复习·已掌握 / 难度 不限·初·中·高 / 来源 不限·官方·手动·AI·JD)+ 模块下拉(随分类)+ 计数。
- **表格**(可排序,表头点击切换方向):题号 | 题干 | 模块 | 难度 | 状态 | 下次复习 | 笔记标(有笔记的行显示书签图标)。行点击选中,↑/↓ 移动选中。
- **详情栏**(右侧 360px):meta 药丸 + 题干 + 考察方向/下次复习 + 操作区(学习此题;我的题:编辑/删除;官方题:复制到我的题库)+ 参考答案要点 + 追问 + **笔记**(就地查看/编辑/新增)。
- 编辑=详情栏内表单(题干/答案要点),保存即生效;删除=确认弹窗(连带进度/笔记/草稿删除说明)。
- **空态**:无匹配 →「没有匹配的题」+ 清除筛选;我的题库空 → 引导添加题目。

### 4.4 待审核

- 左:列表(来源行「AI 生成 · 知识点 X」/「按 JD 生成 · 岗位名」+ 题干);右:详情(要点 + 追问展示同题库)。
- **通过,进我的题库**(立即生效,计数联动)/ **拒绝**(确认弹窗:永久删除)。
- 空态:「没有待审核的题」+ 去添加题目。

### 4.5 添加题目(三段平铺,术语表固定)

- **手动写题**(左卡):题干* / 考察方向* / 难度分段(初中高)/ 答案要点*(每行一条,合计 ≥50 字,QUALITY 红线提示)→ **保存到我的题库**(人写即人审,直接 approved,来源 manual)。
- **AI 生成**(右上):知识点* → 生成中(spinner + 说明「数量由 AI 按知识点广度判断」)→ 结果内联展示 + 「去审核」。
- **按 JD 生成**(右下):JD 单选卡 + ☑ 结合简历,生成深挖题 → 生成中 → 待审核。
- 从 JD 详情深链进入时:按 JD 段高亮 + 预选。

### 4.6 JD 管理

- 左:JD 列表(岗位名 / 公司 · 最近使用);右:详情——meta(公司/最近使用)+ **管线统计**(待审核 N / 已入我的题库 N / 已掌握 N)+ 操作(按此 JD 生成题目(主)/ 编辑 JD / 删除(确认))+ JD 正文 + 简历块(字数 + 编辑简历跳转)。
- 新增/编辑 = 详情栏就地表单(岗位名*/公司/JD 正文*),**dirty 守卫**;保存后「最近使用=刚刚」置顶。

### 4.7 简历管理

- 编辑器版式:标题栏(我的简历 / 实时字数(未保存时标注)/ **只存本机**徽标 / 保存按钮——无修改时禁用)+ 大编辑区(Monospace)。
- dirty 守卫:「放弃修改并离开」会**恢复为已保存内容**再离开。

### 4.8 设置

- **AI 服务**:服务商分段(智谱/DeepSeek/Ollama)+ API Key(password 输入 + 保存;「已保存 · 仅存本机,不上传」)。
- **学习偏好**:每次学习题量(20/50/全部;先待复习后待学习);外观(浅色纸面/夜读,**真实切换**)。
- **题库与数据**:官方题库同步(上次同步时间 + 立即同步);备份导出/导入(app 层,不走 git,ADR-7)。

## §5 ⌘K 命令面板

- 输入即搜,三组结果:**动作**(开始复习 N 题 / 开始学习 N 题 / 添加题目 / 再过一遍——零计数的复习/学习项自动隐藏)、**前往**(七表面)、**题目**(全库题干/考察点/题号/模块模糊匹配,回车跳题库并选中详情)。

## §7 文案规范(术语表之上的新增固定短语)

- 评分反馈 toast:「已掌握 · 7 天后再学」「模糊 · 3 天后再学」「『不会』的题稍后会再出现一次」
- 小结:「本轮学习完成」「学习了 N 道题,掌握 N 道,偏弱 N 道已排进明天」「N 天后再学 / 明天 · 优先」
- 学习空态:「从这里开始一轮学习」「先取待复习,再取待学习补位」
- 全清态:「今日队列已清空」「复习与新题都完成了,明天见」
- 生成:「正在按知识点出题,数量由 AI 判断…」「正在围绕『岗位』出题,结合简历深挖…」「已生成 N 题,先进待审核」
- 守卫:「有未保存的修改」「离开将丢弃当前修改。可先保存再离开。」/ 放弃修改并离开 / 继续编辑
- 确认弹窗:「删除这道题?」「该题的学习进度、笔记、代码草稿一并删除,不可恢复。」/「拒绝这道题?」「将被永久删除,不可恢复。」
- 同步:「官方题库已是最新」;备份:「已导出备份文件」
- 状态栏:「本地优先 · 数据不上传」

## §8 视觉规范

- **皮肤**:暖纸 token 家族——paper/card/input/sidebar 四层纸面 + ink/mut/cin(朱砂)墨色 + ok/warn/bad 语义色;层次由面色分层 + 轻阴影承担,全站无边框发丝线(仅用 line 色做分隔与描边)。
- **夜读**:`body.night` 暖黑纸变量伴生(同一批 token 换值,无新色调);pill/按钮 hover 均有夜读覆盖。
- **字体**:系统无衬线做正文;**宋体 display(`--font-display`)只用于四处**——页头 h1、学习题干、小结标题、JD 详情标题。
- **字号阶梯**:10.5 / 11 / 11.5 / 12.5 / 13.5(正文)/ 15–16(详情题干)/ 18(页头)/ 21–22(题干)/ 27(专注题干)。
- **密度**:侧栏 196px;详情栏 360px;题卡 ≤640px(≈38rem);表格行高 ~36px;圆角 7(按钮/输入)–10(卡片)。
- **图标**:15px 线性 stroke SVG(1.7 描边),侧栏/功能按钮用;**禁止 emoji 与文本字符充当图标**。
- **表格列宽**(1440 视口参考):题号 84 / 题干 auto / 模块 92 / 难度 44 / 状态 78 / 下次复习 88 / 笔记标 26。
- **动效**:150–220ms 过渡;评分推进 220ms 淡出;尊重 `prefers-reduced-motion`。
- **可达性**:focus-visible 朱砂描边;色彩不做唯一信息通道(状态 pill 有文字)。
