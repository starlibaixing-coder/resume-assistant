# 题库清洗 Prompt

将任意格式的题库原料（Markdown / 网页文本 / 散乱笔记）清洗成标准 YAML 题库格式。

## 输入

用户会提供一段题库原料文本，可能包含题目、答案、解析等，格式不固定。

## 输出格式

严格输出以下 YAML 结构（每模块一个文件的内容）：

```yaml
module: <模块编号，整数>
moduleName: "<模块名称>"
questions:
  - id: "<两位模块号>.<题号>"
    difficulty: <初 | 中 | 高>
    tags: [<标签1>, <标签2>]   # 无标签则为 []
    title: "<题目标题>"
    focus: "<考察点，一句话>"
    answer:
      - "<答案要点1，一条一个 bullet>"
      - "<答案要点2>"
    followups:
      - "<追问方向1>"   # 无则为 []
```

## 清洗规则

1. **难度归一**：原料里的难度标记（⭐、星级、初级/中级/高级等）统一映射为 `初`/`中`/`高`。无明确难度的归 `中`。
2. **id 格式**：`<两位模块号>.<题号>`，题号在模块内从 1 递增。如 `01.1`、`01.2`、`02.1`。
3. **answer 是 bullet 数组**：把原料的答案内容拆成要点，每条一个数组元素。保留加粗等 markdown 内联格式。**总字数必须 ≥ 50**。
4. **focus 一句话**：从原料提炼考察点，简明扼要。
5. **followups**：原料里的"追问""延伸"类内容归这里；无则空数组 `[]`。
6. **保留技术准确性**：不编造内容，不改变原意。原料不清楚的地方标注待核实，不要瞎补。
7. **丢弃无关内容**：出处、来源链接、版权声明等不进 YAML。

## 示例

输入片段：
```
### 什么是 ReAct？
难度：⭐⭐⭐
一句话：边想边做的 Agent 范式。
详解：ReAct 是 Reasoning + Acting 的循环...
追问：为什么容易跑偏？
```

输出：
```yaml
module: 1
moduleName: "Agent 核心机制"
questions:
  - id: "01.1"
    difficulty: 中
    tags: []
    title: "什么是 ReAct？"
    focus: "理解 ReAct 边想边做的 Agent 范式。"
    answer:
      - "**ReAct**（Reasoning + Acting）：边想边做，每一步 Thought -> Action -> Observation 循环。"
      - "适合任务步数不定、需动态决策的场景。"
      - "缺点是易跑偏、步数不可控。"
    followups:
      - "为什么容易跑偏？"
```
