# 题目设计质量原则

> 题库质量的两个层面：**格式完整性**（build.mjs 强制）+ **题目设计质量**（本文件 + audit.mjs 检查）。
> 格式检查答案长度/字段；本文件检查题目本身设计得对不对、好不好。

## 四条设计缺陷

### 缺陷 1：答案泄漏进题干

题干的后半句直接回答了前半句，或题干本身包含了答题人该自己想到的要点。

- ❌ `什么是 Function Calling？LLM 是怎么学会调用外部工具的？` — 后句就是前句的答案（Function Calling 就是调外部工具）
- ❌ `手写 new 操作符的实现。new 做了哪些事？` — 知道 new 做了哪些事就能手写，后句是前句的提示
- ✅ `什么是 Function Calling？`
- ✅ `手写 new 操作符的实现`（不附带提示）

### 缺陷 2：追问隐含答案

追问把题干该考的区分点点名了，或追问括号里直接给了答案。

- ❌ `箭头函数和普通函数有哪些区别？为什么箭头函数不能用作构造函数或方法？` — "不能做构造函数"是区别之一，题干点名了
- ❌ 追问 `只用 O(1) 空间怎么做？（计数 left/right）` — 括号里是答案
- ✅ `箭头函数和普通函数有哪些区别？` + 追问 `箭头函数能否作为构造函数？为什么？`（不点名区别，让答题人自己想到）

### 缺陷 3：一题塞多个无递进关系的独立问题

子问题之间没有"后问是前问的自然延伸"关系，硬凑一题。

- ❌ `HTTP/2 和 HTTP/3 相比 HTTP/1.1 有什么改进？为什么 HTTP/3 改用 UDP？` — "三版本对比"和"why UDP"是两个独立问题，该拆
- ✅ `HTTP/2 相比 HTTP/1.1 有什么改进？`（一题）+ `HTTP/3 为什么改用 UDP？`（另一题）
- ✅ `什么是 BFC？如何触发？有哪些应用场景？` — 三问递进（是什么 → 怎么做 → 用在哪），合理

**判断标准**：子问题之间有递进关系（是什么 → 怎么做 → 用在哪 / 是什么 → 为什么 → 怎么办）可留一题；无递进（两个独立知识点并排）该拆。

### 缺陷 4：概念层次混乱

题目把不同层次的概念并列或混用，误导答题人。

- ❌ Function Calling 和 Tool Use 混为一谈（tool use 是更上层概念，基于 function calling 实现）
- ❌ 把"浏览器渲染过程"和"关键渲染路径"当成同义词提问（后者是前者的性能优化子集）

### 缺陷 5：focus（考察点）泄漏答案

focus 字段应写"这道题考察什么能力"，不是答案摘要。如果 focus 把答案结论说完了，答题人看 focus 就等于看了答案。

- ❌ focus: "Function Calling 让 LLM 输出结构化的工具调用，由外部代码执行后喂回 LLM。本质是 LLM 学会了识别时机+生成 JSON" -- 这是答案浓缩，不是考察点
- ✅ focus: "理解 Function Calling 的本质：LLM 负责生成调用指令，外部代码负责执行" -- 点明考察方向，不给完整答案
- ❌ focus: "SSE 是服务器单向推消息的协议，和 WebSocket 区别是 SSE 单向基于 HTTP..." -- 答案全说了
- ✅ focus: "区分 SSE 和 WebSocket 的通信方向与协议基础" -- 只说考察什么

**判断标准**：focus 超过 40 字且关键词与答案高度重叠（≥5 个实词），疑似答案泄漏。

## 自动化检查（audit.mjs 实现）

| 检查项 | 自动化程度 | 规则 |
|---|---|---|
| 多问一题 | 启发式 | 题干含 ≥2 个 `？`，标记"疑似多问，需确认是否递进" |
| 追问括号提示 | 启发式 | 追问含 `（...）` 且括号内 >5 字，标记"疑似含答案提示" |
| 题干自我回答 | 启发式（误报高） | 题干后半句关键词在答案中出现，标记"疑似答案泄漏" |
| 概念层次混乱 | AI 审查 | 无法自动化，纳入 AI 审查 prompt |

## AI 审查 prompt 补充

AI 审查不只看答案正确性，还要按以上 4 条原则审**题目设计**：

```
审查以下面试题。检查两方面：
1. 答案有无硬错误（事实性/技术性）
2. 题目设计是否有缺陷：
   - 答案是否泄漏进题干（后半句回答前半句）
   - 追问是否隐含答案（括号提示/点名区分点）
   - 是否一题塞多个无递进关系的独立问题
   - 概念层次是否混乱（不同层次概念并列/混用）
有问题指出并给修正建议，标注置信度（高/中/低）。无问题回复"无问题"。
```
