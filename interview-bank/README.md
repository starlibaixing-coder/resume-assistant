# AI Agent 工程师面试题库

> 面向**生产级 Agent 开发岗位**（字节/美团/Coding Agent 等 JD）的结构化面试题库。
> 目标:覆盖从「底层模型原理」到「上层认知定位」的完整能力栈,既能**直接备考**,也能作为**出题题库**使用。

## 题目规范

每道题统一格式:

```
### Q[模块号.序号]【难度】题目标题

**考察点:** 一句话说清面试官想看什么。

**参考答案要点:**
- 要点 1(分点作答,体现层次)
- 要点 2

**追问方向:** (可选)面试官常见的延伸追问。
```

**难度分级:**
- 【初】基础概念,能讲清原理即可
- 【中】需结合场景,能给出具体方案
- 【高】系统设计/深度推理,体现架构能力与生产经验

## 使用方式

### 按岗位刷题
- 投 **JD2(字节·数据中台算法岗)**:12 → 05 → 06 → 10 → 11 → 15
- 投 **JD4(Coding Agent)**:12 → 13 → 14 → 07 → 11 → 09 → 15
- 投 **JD3(美团·M 端)**:01 → 03 → 04 → 09 → 10 → 13 → 15
- 投 **JD1(字节·底座)**:01 → 04 → 06 → 08 → 14 → 15

### 通用备考路径(从底层往上)
1. **先打地基**:模块 12(模型原理)→ 01(核心机制)
2. **再学搭建**:03(RAG)→ 02(范式)→ 04(框架)→ 06(评测)
3. **然后上线**:09(踩坑)→ 10(工程化)→ 08(工具)
4. **拔高产品**:13(产品架构)→ 14(工作流)
5. **收尾认知**:15(行为面)

### 自查标准
能流畅回答每个模块 Top 3 题,基本过线。
能展开讲清每个模块的"系统设计"题(标注【高·系统设计】),达到 senior 水平。
